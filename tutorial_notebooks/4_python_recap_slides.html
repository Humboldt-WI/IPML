Inheritance & polymorphism

  • A subclass reuses its parent attributes and methods.
  • super() calls the parent implementation.
  • Overriding changes an inherited method.
  • Polymorphism: the same method call selects behaviour according to the object.
Predict & explain

Which method implementation does each object use?

class Sound:
    def __init__(self, name):
        self.name = name
    def play(self):
        return "ding"

class Drum(Sound):
    def __init__(self, name):
        super().__init__(name)
    def play(self):
        return "boom"

for sound in [Sound("bell"), Drum("bass")]:
    print(sound.name, sound.play())
Reveal output

bass boom
